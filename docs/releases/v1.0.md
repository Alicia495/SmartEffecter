# SmartEffecter v1.0

ギター・ベースにエフェクトをかけ、PCマイクと合成してDiscordなどへ送れるWindowsアプリです。
自分にはエフェクト後の楽器音だけを、選択したヘッドホンへ返せます。

## ダウンロード

- **SmartEffecter-v1.0-windows-x64.zip**：通常はこちら。展開して `GuitarSmartEffecter.exe` を起動。
- **SmartEffecter-v1.0-source.tar.gz**：アプリ、依存クレート、使用したASIO SDK部分を含む対応ソース。
- **SHA256SUMS.txt**：ダウンロードしたアーカイブの確認用。

Windows 10 / 11 x64、入力機器のASIOドライバーが必要です。
Discordへ渡す場合はVB-CABLEを別途導入し、Discordの入力をCABLE Outputにしてください。

[使い方](https://github.com/Alicia495/SmartEffecter/blob/v1.0/README.md) · [詳しい設定](https://github.com/Alicia495/SmartEffecter/blob/v1.0/docs/SETUP.md)

25件のテスト、コード検査、画面操作を確認。M-Track・Ankerマイク・VB-CABLE・別出力の短時間動作も確認しています。
AG03MK2実機、Discordの受信音、実演奏の聴感、電気的な往復遅延は未確認です。別機器やBluetoothでは遅延が増えます。
