# SmartEffecter v1.1

メトロノームと音切れ診断ログを追加し、音作り・ミキサー画面を刷新しました。

## 主な変更

- **メトロノーム**：30～300 BPM、1～12拍、音量調整、先頭拍のアクセント。ミキサーから操作できます。クリック音はメイン出力（Discordを含む）と自分用モニターの両方に送られます。
- **音切れの診断ログ**：欠落・オーバーフロー・処理期限超過・ドライバーエラーなどを自動保存。設定の「ログを開く」から取得できます。音声録音・自動送信はしません。
- **Studio UI**：Bento／ガラス調のダーク・ライト画面、円形ノブの数値入力、楽器だけのトリガー式波形、Guitar／Bassごとの調整状態の保存。
- **マイクON／OFF**：入力・合成処理ごと停止でき、接続先と音量は保持します。接続中の切り替えでは再接続に伴う短い音切れがあります。
- **音声処理の改善**：DSP係数計算の負荷削減、微小信号処理の負荷対策、音量変更時の補間、ミックス時のソフトクリップ。

## ダウンロード

- **SmartEffecter-v1.1-windows-x64.zip**：推奨。EXE・使い方・ライセンス一式。展開して `GuitarSmartEffecter.exe` を起動してください。
- **GuitarSmartEffecter.exe**：実行ファイル単体。既存環境の更新用です。
- **SmartEffecter-v1.1-source.tar.gz**：依存クレートと使用したASIO SDK部分を含む対応ソース。
- **SHA256SUMS.txt**：配布ファイルのSHA-256チェックサム。

Windows 10／11 x64と、入力機器のASIOドライバーが必要です。Discordへ送る場合はVB-CABLEを別途導入してください。既存の設定・プリセットは引き継げます。メトロノームは起動時OFFです。

## 検証と制限

通常テスト31件、コード検査、ネイティブUI操作を確認。M-Trackでマイク切り替えと短時間のログ保存を確認しています。報告された音切れの原因特定、実演奏でのメトロノームの聴感、長時間連続動作、AG03MK2実機、Discordの受信音は未確認です。
